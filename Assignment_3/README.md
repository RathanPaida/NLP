# Assignment 3 — Finite Automata for NLP

## Overview

This assignment explores **formal language theory** applied to NLP through two problems:

1. **DFA** — Deterministic Finite Automaton for validating simplified English words.
2. **FST** — Finite State Transducer for English noun morphological analysis (singular/plural).

---

## Question 1 — DFA for Valid English Words

### Problem
Design and implement a DFA that **accepts** strings matching the pattern of valid simplified English words (sequences of alphabetic characters, at least 2 characters long) and **rejects** everything else (strings with digits, special characters, single characters, etc.).

### Implementation
- Uses the **`automathon`** library to build and visualize the DFA.
- The alphabet covers all printable ASCII characters.
- Includes automated test cases and an interactive testing section.

### Key Files
| File | Description |
|------|-------------|
| `Question_1_DFA.ipynb` | DFA construction, visualization, and testing |
| `dfa_english_word.gv` | Graphviz source for the DFA diagram |
| `dfa_english_word.gv.png` | Rendered DFA state diagram |

---

## Question 2 — FST for Noun Morphology

### Problem
Build an FST that performs **morphological analysis** on English nouns — determining whether a word is singular, plural, or invalid, and identifying which pluralisation rule was applied.

### Plural Rules Implemented
| Rule | Example |
|------|---------|
| **S-addition** | `cat` → `cats` |
| **E-insertion** | `church` → `churches` (after _s, sh, ch, x, z_) |
| **Y-replacement** | `city` → `cities` (consonant + _y_ → _ies_) |

### Implementation
1. **Extract nouns** from `brown_corpus.pdf` using `PyPDF2`.
2. **Build a lexicon** of valid nouns from the Brown Corpus.
3. **Implement the FST** as a Python class (`NounMorphFST`) with state transitions.
4. **Visualize** the FST and plural-suffix sub-FST using Graphviz.
5. **Run** on all Brown Corpus nouns and report breakdowns.
6. **State minimization analysis** and interactive trace demo.

### Key Files
| File | Description |
|------|-------------|
| `Question_2_FST.ipynb` | FST construction, visualization, and full evaluation |
| `brown_corpus.pdf` | Source PDF of Brown Corpus nouns |
| `brown_nouns.txt` | Extracted nouns (generated by the notebook) |
| `fst_noun_morph.png` | FST state diagram |
| `fst_plural_rules.png` | Plural-suffix sub-FST diagram |
